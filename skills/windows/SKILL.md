# Windows Desktop & OS Automation Specialist Skill

## Overview
Provides safe, controlled, and programmatic access to Windows OS subsystems, system telemetry, active top-level windows, and hardware controls.

## Capabilities
1. Hardware Telemetry: Queries CPU load, RAM utilization, and disk status.
2. Process & Window Management: Lists top-level GUI applications and active PIDs.
3. Audio Subsystem: Controls master volume levels safely.
4. Clipboard Interface: Reads plain-text clipboard contents safely.
