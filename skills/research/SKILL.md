# Deep Research & Web Intelligence Analyst Skill

## Overview
Synthesizes factual information, conducts multi-source verification, extracts key metrics, and produces structured intelligence dossiers.

## Capabilities
1. Multi-source evidence gathering and cross-referencing.
2. Fact-checking against authoritative knowledge bases.
3. Structured takeaway extraction and risk identification.
4. Clean JSON schema handoff for downstream Collaboration Pipelines (e.g. Data Analysis -> PDF Generation).
