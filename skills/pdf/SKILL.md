# Compact Publication-Grade PDF Generator Skill

## Overview
Generates publication-grade, compact research reports formatted specifically for high information density, clean typography, and zero wasted white space.

## Design Rules
- Standard A4 page format with 35-45pt margins.
- Clean typography hierarchy (Heading 14-16pt, Body 9.5-10.5pt, Line height 1.25-1.35).
- Prevent forced page breaks and isolated lines.
- Dense data tables with 4-6pt cell padding.
- Embeds running header and compact footer with page numbering.
